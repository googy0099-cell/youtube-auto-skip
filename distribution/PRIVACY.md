# ความเป็นส่วนตัว — 1.4.1

ไม่มีเซิร์ฟเวอร์ผู้พัฒนา บัญชี analytics SDK โฆษณา โค้ดจากภายนอก หรือการอัปโหลดข้อมูล เก็บกฎเว็บ สถานะ และตัวระบุปุ่มไว้ใน Chrome ของผู้ใช้ ไม่เก็บประวัติ คุกกี้ รหัสผ่าน ชื่อคลิป หรือพาธหน้าเว็บ ไม่ซิงก์ผ่านส่วนขยายนี้

เมื่อเพิ่มเว็บ Chrome จะขอสิทธิ์ทุกเว็บไซต์ HTTP/HTTPS เพื่อเข้าถึงตัวเล่นฝังจากโดเมนใดก็ได้ เป็นสิทธิ์กว้างจริง ตัวโหลดขนาดเล็กอาจทำงานในเฟรมที่มีสิทธิ์ แต่เริ่มสแกน DOM และกดเฉพาะเมื่อเว็บหลักอยู่ในรายการที่เปิดใช้ เว็บอื่นไม่เริ่มตัวสแกน

หน้าจัดการอ่านแท็บต้นทาง เปิด URL ที่ผู้ใช้กรอก และแสดงโดเมนเฟรมกับสถานะตรวจสอบในเครื่อง สถานะในหน้าเว็บจำกัดจำนวนและหายเมื่อรีเฟรช เว็บอ่านสถานะนี้ได้ การกดปุ่มอาจทำให้เว็บส่งข้อมูลตามการทำงานปกติของเว็บเอง

debugger เป็นสิทธิ์กว้างเดิม แต่โค้ดใช้เฉพาะส่งเมาส์ใน HTTPS YouTube ระดับบนที่ตรวจแล้วและถอดการเชื่อมต่อทันที ไม่ตรวจเครือข่าย อ่านคุกกี้ หรือประเมิน JavaScript ผ่าน debugger ส่วน storage เก็บการตั้งค่า, scripting โหลดตัวตรวจและอ่านสถานะเฟรม, activeTab จำแท็บต้นทาง

Pause เก็บสิทธิ์ไว้ Remove หยุดเว็บและลบกฎ สิทธิ์ทุกเว็บยังอยู่ตราบที่มีรายการอื่นใช้งาน และคืนเมื่อเอาเว็บสุดท้ายออก ผู้ใช้เพิกถอนสิทธิ์ผ่าน Chrome ได้ ถอนการติดตั้งลบข้อมูลส่วนขยายในเครื่อง

รุ่นทดลองยังไม่มีข้อมูลติดต่อผู้เผยแพร่ ก่อนส่ง Store ต้องใส่ข้อมูลจริงและโฮสต์นโยบาย อ่านรายละเอียดอังกฤษใน PRIVACY-EN.md

Pending Add requests store only origin, action, token and source tab ID in Chrome session memory. They cannot be applied after 60 seconds and are cleared when processed or when the browser session ends. This permits saving after Chrome closes a permission-request popup.
