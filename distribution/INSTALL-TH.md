# YouTube Auto Skip 1.4.1

YouTube เป็นค่าเริ่มต้น ไม่มีเว็บอื่นกำหนดมาให้ เพิ่มเว็บ HTTP/HTTPS เองได้โดยไม่ต้องให้ผู้พัฒนาเขียนตัวรองรับรายเว็บ

ติดตั้ง: แตก ZIP → chrome://extensions → Developer mode → Load unpacked → เลือกโฟลเดอร์ youtube-auto-skip ที่มี manifest.json ใช้ Chrome 119 ขึ้นไป หากมีรุ่นเดิมให้แทนไฟล์ในโฟลเดอร์เดิม กด Reload และรีเฟรชหน้าวิดีโอ ไม่ต้องติดตั้งซ้ำ

เปิดเมนูจากไอคอนส่วนขยายใน Chrome ไม่ใช่เปิดไฟล์ manage.html โดยตรง

เพิ่มเว็บ: กรอก URL → Add หรือกด Add current website → อนุญาต Chrome แล้วกลับไปเล่นวิดีโอ เมนูเป็นกล่องเล็กใต้ไอคอน ไม่เปิดแท็บตั้งค่าใหม่ การเพิ่มบันทึกเว็บไว้โดยไม่เปิดแท็บ หากต้องการไปเว็บนั้นใช้ Open in this tab ได้

Chrome ขอสิทธิ์อ่านและเปลี่ยนข้อมูลทุกเว็บไซต์ HTTP/HTTPS ครั้งเดียว เพื่อเข้าถึงตัวเล่นวิดีโอที่ฝังจากโดเมนใดก็ได้ โค้ดจะตรวจปุ่มและกดเฉพาะเว็บที่เปิดไว้ในรายการของผู้ใช้ เฟรมต่างโดเมนรวมให้อัตโนมัติ ไม่ต้องเพิ่มโดเมนตัวเล่นทีละตัว รายการจากรุ่นเก่าใช้ Enable automatic players เพื่อเปิดความสามารถนี้

ตรวจจากข้อความปุ่มข้ามโฆษณา ชื่อ accessibility และตัวระบุปุ่ม ไม่ผูกกับชื่อเว็บหรือตัวเล่นแบบเดียว รองรับปุ่ม custom และ open shadow DOM เลี่ยงปุ่มที่ซ่อน ถูกบัง ปิดใช้ หรือนับถอยหลัง ไม่กด Skip intro หรือปุ่มดาวน์โหลด

Check detection แสดงผลแต่ละเฟรม แยกการส่งคลิกกับการเห็นปุ่มตอบสนอง หากกดแล้วไม่เห็นการเปลี่ยนแปลงจะแสดงว่ายังยืนยันไม่ได้ และหยุดลองเมื่อปุ่มเดิมไม่ตอบสนองสามครั้ง

Choose a Skip button เป็นทางเลือกสำหรับปุ่มที่ยังตรวจไม่เจอ, Reset button กลับไปตรวจอัตโนมัติ, Pause พัก, Enable เปิดกลับ, Remove ลบและหยุดเว็บนั้น สิทธิ์ทุกเว็บยังอยู่ถ้ามีรายการอื่นใช้อยู่ และคืนสิทธิ์กว้างเมื่อเอาเว็บสุดท้ายออก

ไม่รับประกันทุกเว็บ: บางเว็บปฏิเสธคลิกจากสคริปต์ ใช้ canvas หรือ closed shadow DOM ไม่สามารถข้ามโฆษณาที่ไม่มีปุ่มข้ามได้ ระบบ YouTube เดิมไม่เปลี่ยน อาจมีแถบ debugging ของ Chrome

ข้อมูลเว็บและปุ่มเก็บในเครื่อง ไม่มีระบบส่งข้อมูลให้ผู้พัฒนา ZIP เป็นรุ่นทดลอง ยังไม่ใช่ส่วนขยายที่อนุมัติใน Store
